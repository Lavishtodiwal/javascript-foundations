# Git important commands

## git init

``` Bash
git init // used to initialized the git repository
```

## git  status

``` Bash
git status// used to check the status of the stagging and changes
```

## git  add .

``` Bash
git add . // used to add the current folder to the stagging area
```

## git  commit

``` Bash
git commit -m "first commit" // used to save the snapshot of the changes
```

