







# Cloud Computing

Cloud computing is the delivery of computing services such as servers, storage, databases, networking, and software over the internet, usually on a pay-as-you-go basis.

**Easy example**: Instead of buying a physical computer server to host your website, you rent a server from AWS or Azure and access it through the internet.

### Cloud services are primarily organized into three tiers:

- IaaS (Infrastructure as a Service): You rent raw virtual machines and storage. You manage the operating system and apps; the provider manages physical hardware. (Example: AWS EC2, Google Compute Engine) 
  - **Easy meaning**: Server rent par lena; operating system aur applications tum manage karte ho.



- PaaS (Platform as a Service): You bring only your code. The provider manages the underlying servers, operating systems, and runtimes. (Example: Heroku, AWS Elastic Beanstalk)
  - Application develop aur deploy karne ke liye ready-made platform provide karna.
- SaaS (Software as a Service): Ready-to-use software delivered entirely through a web browser. (Example: Google Drive, Gmail, Netflix)

### Easy Trick to Remember

1. aaS: Infrastructure rent karo.

2. PaaS: Platform use karo.

3. SaaS: Software use karo.
### Key terms

- **Server**: A computer that provides services or data to other computers.

- **Storage**: A place to save files and data.

- **Database**: A system for storing and managing structured data.

- **Scalability**: The ability to increase or decrease resources based on demand.

 
# DevOps

DevOps is a combination of practices, tools, and a culture that brings software development (Dev) and IT operations (Ops) teams together to build, test, release, and maintain software faster and more reliably

**Easy example**: A developer updates a website's code. Instead of manually testing and uploading it, a DevOps pipeline automatically tests the code and deploys it to a server.

**Real-life example**: When an online shopping app releases a new feature, DevOps practices help automate testing, deployment, and monitoring.

### Key terms

- **CI (Continuous Integration)**: requently merging code changes and automatically testing them.

- **CD (Continuous Delivery/Deployment)**: Automating the process of preparing or releasing software updates.

- **Automation**: Using tools to perform repetitive tasks automatically.

- **Monitoring**: Tracking an application's performance, errors, and availability













# Difference Between Cloud Computing and DevOps

| Cloud Computing | DevOps |
|---|---|
| Provides computing resources over the internet. | Combines development and operations practices. |
| Focuses on infrastructure and services. | Focuses on software delivery and operations. |
| Examples: AWS, Azure, Google Cloud. | Examples: GitHub Actions, Jenkins, Docker. |
| Helps host and scale applications. | Helps build, test, deploy, and maintain applications. |

# Cloud computing basics

### Definition

Cloud Computing is the delivery of computing services such as servers, storage, databases, networking, and software over the internet, allowing users to access resources on demand without owning physical infrastructure.

### Easy Explanation (Hinglish)

Cloud Computing ka matlab hai internet ke through kisi doosre computer ke resources (jaise server, storage, database) ko use karna, bina khud ka physical server kharide.

### Maan lo tum ek website bana rahe ho:

- Tumhe website ko internet par live karna hai.

- Apna physical server kharidna expensive hoga.

- Tum AWS ya Google Cloud se server rent kar sakte ho.

- Users internet ke through tumhari website access kar sakte hain.

Yahi Cloud Computing hai.

## Why Do We Need Cloud Computing?

Traditional method mein company ko khud server kharidna, maintain karna aur upgrade karna padta tha.

Cloud Computing mein ye kaam cloud provider ki infrastructure par hota hai.

| Traditional Computing | Cloud Computing |
|---|---|
| Physical server kharidna padta hai. | Server rent par le sakte hain.. |
| Hardware maintenance khud karni hoti hai. | Infrastructure provider manage karta hai.. |
| Capacity badhane ke liye hardware kharidna padta hai. | Resources ko quickly scale kar sakte hain. |
| High initial investment ho sakta hai. | Usage ke hisaab se payment kar sakte hain. |

**On-Demand**

Jab zarurat ho tab resources use karo.

 **Scalability**

Resources increase ya decrease karna.

**Pay-as-you-go**

Usage ke according payment.

**Resource Pooling**

Shared infrastructure se multiple customers ko resources dena.

**Accessibility**

Internet ke through resources access karna

## Important Cloud Computing Terms


**Virtual Machine (VM)**:
Software-based computer running on physical hardware.




**Region**: Geographic area where a cloud provider operates infrastructure.




**Availability Zone**:
Isolated location within a cloud region.




**Storage**:
Cloud mein files aur data save karna.




**Database** :
Data ko organize aur manage karna.




**Serverless**:
Infrastructure management ko cloud provider ke through abstract karna.




**Load Balancer**
:Incoming traffic ko multiple servers mein distribute karna.




**Auto Scaling**
:Demand ke according resources automatically adjust karna.
